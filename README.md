# Portfolio — Emiliano La Paz

Portfolio personal full stack de Emiliano La Paz, construido con Next.js, TypeScript y Tailwind CSS.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS v4
- [lucide-react](https://lucide.dev)

## Desarrollo local

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Contenido

Los datos personales (perfil, experiencia, skills, certificaciones, proyectos) viven en [`src/data/profile.ts`](src/data/profile.ts).
